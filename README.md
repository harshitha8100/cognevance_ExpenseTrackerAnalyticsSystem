Expense Tracker & Analytics System

Project Overview

Expense Tracker & Analytics System is a Python-based application designed to manage personal expenses efficiently. The system allows users to add, view, update, and delete expense records while generating reports and visual analytics.

Features

- Add new expenses
- View all expenses
- Update existing expenses
- Delete expenses
- Generate expense reports
- Visualize expenses using charts
- SQLite database integration
- User-friendly menu-driven interface

Technologies Used

- Python
- SQLite3
- Matplotlib

Project Structure

ExpenseTrackerAnalyticsSystem/

├── expense_tracker.py

Installation

1. Clone the repository:
   git clone <repository-link>

2. Open the project folder in VS Code.

3. Install required packages:
   pip install matplotlib

4. Run the application:
   python expense_tracker.py

Usage

1. Add Expense
2. View Expenses
3. Update Expense
4. Delete Expense
5. Generate Report
6. Show Chart
7. Exit

Database

The application uses SQLite database to store expense records.

Table: expenses

- id
- category
- amount
- date
